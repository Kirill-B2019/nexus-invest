# Nmess — мессенджер НЕКСУС

Мессенджер для платформы НЕКСУС: текстовые сообщения, голосовые и видеозвонки. Код изолирован в папке `Nmess/` (вариант B).

## Структура

- **server/** — сервер сигналинга (Node.js, WebSocket). Запуск: `cd server && npm install && npm start`.
- **client/** — SPA клиент (Vue 3 + Vite). Сборка: `cd client && npm install && npm run build`. Результат в `client/dist/`.
- **docs/** — ТЗ и описание API.

## Локальный запуск

### Сервер сигналинга

```bash
cd Nmess/server
cp .env.example .env
# Отредактировать .env: порт, URL Laravel API, секрет JWT
npm install
npm start
```

По умолчанию сервер слушает порт из `PORT` в `.env` (например 3001).

### Клиент (разработка)

```bash
cd Nmess/client
npm install
npm run dev
```

Сборка для встраивания в ЛК:

```bash
npm run build
```

После сборки скопировать содержимое `client/dist/` в `public/nmess/` (в т.ч. `index.html` и папку `assets/`), а также `client/public/logo-head.svg` в `public/nmess/`. Либо выполнить из корня проекта:

```bash
xcopy /E /Y Nmess\client\dist\* public\nmess\
copy Nmess\client\public\logo-head.svg public\nmess\
```

### Laravel

- Выдача токена для мессенджера: `GET /api/nmess/token` (для авторизованного пользователя с правом доступа).
- Страница мессенджера в ЛК: `/lk/messenger`.
- Раздел «Управление мессенджером»: `/lk/admin/messenger` — только для роли **Админ мессенджера** (`messenger-admin`).

### Роль «Админ мессенджера»

1. **Создать роль** (один раз):
   ```bash
   php artisan db:seed --class=RoleMessengerAdminSeeder
   ```

2. **Назначить роль пользователю** (в tinker или в коде):
   ```bash
   php artisan tinker
   >>> \App\Models\User::find(1)->assignRole('messenger-admin');
   ```
   Или по email: `User::where('email', 'admin@example.com')->first()->assignRole('messenger-admin');`

3. **Как посмотреть:** войти в ЛК под пользователем с ролью `messenger-admin` — в боковом меню (Панели) появится пункт **«Управление мессенджером»**. Либо открыть напрямую: `/lk/admin/messenger`. Без роли маршрут вернёт 403.

## Как протестировать мессенджер

1. **Запустить сервер сигналинга** (в отдельном терминале):
   ```bash
   cd Nmess/server && npm start
   ```
   Должно появиться: `Nmess signaling server listening on port 3001`.

2. **Запустить сайт** (если ещё не запущен):
   ```bash
   php artisan serve
   ```

3. **Войти в ЛК:** открыть http://127.0.0.1:8000/login, войти под пользователем (например **k@test.ru** или **i@test.ru**, пароль **password**).

4. **Если в списке контактов нет i@test.ru (или других тестовых пользователей)** — создать/обновить пользователей:
   ```bash
   php artisan db:seed --class=TestUsersSeeder
   ```
   После этого обновите страницу мессенджера (F5).

5. **Открыть мессенджер:** в боковом меню «Панели» → **«Мессенджер»** или перейти по ссылке http://127.0.0.1:8000/lk/messenger.

6. **Как написать и позвонить:** в блоке «Контакты» у каждого пользователя две кнопки:
   - **Написать** — открывает чат с этим контактом (ввод сообщения и кнопка «Отправить»). Второй пользователь должен тоже открыть чат с вами, чтобы видеть сообщения и отвечать.
   - **Позвонить** — отправляет запрос на голосовой звонок; у контакта появляется окно «Входящий звонок» (Принять/Отклонить). Реальный голос по WebRTC пока в разработке.

7. **Проверить:** на странице мессенджера должно отображаться «Сигналинг: подключено». Если «нет» — убедитесь, что сервер на порту 3001 запущен и обновите страницу (Ctrl+F5).

## Деплой на Ubuntu

1. Установить Node.js (LTS).
2. Развернуть сервер: скопировать `Nmess/server/`, установить зависимости, настроить `.env`, запустить через systemd или pm2.
3. Собрать клиент (`npm run build`), скопировать `client/dist/` на сервер и отдавать через nginx или из Laravel `public/`.
4. Настроить TURN/STUN (coturn) при необходимости для WebRTC.
5. В Laravel настроить переменные для URL сигналинг-сервера и при необходимости TURN.
