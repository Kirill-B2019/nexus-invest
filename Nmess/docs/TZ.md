# Техническое задание: мессенджер НЕКСУС (Nmess)

**Версия:** 1.0

## 1. Общие положения

- Мессенджер для экосистемы НЕКСУС: текст, голос, видео. Управление доступом — на сервере; настройки — через кабинет администратора. Интерфейс на русском.
- Код размещается в папке **`Nmess`** внутри проекта (вариант B). Стек — на усмотрение (сервер: Node.js/Go/Python; клиент: JS/TS, Vue/React).

## 2. Структура

- `Nmess/server/` — сервер сигналинга (WebSocket).
- `Nmess/client/` — SPA клиент (сборка в `dist/`).
- `Nmess/docs/` — документация.
- Стили и логотип НЕКСУС копируются в `Nmess/client/` (своя структура, без ссылок на сайт).

## 3. Функциональные требования

- Пользователь = учётная запись НЕКСУС; доступ только при наличии прав из админки.
- Чаты, сообщения в реальном времени, история.
- Голосовые звонки 1-на-1 (обязательно), видеозвонки (желательно).
- Контакты, онлайн/офлайн, уведомления о сообщениях и звонках.

## 4. Управление доступом и админка

- Проверка прав только на сервере при каждом действии.
- В админ-кабинете НЕКСУС: роли/права мессенджера, назначение пользователям, при необходимости аудит/логи.

## 5. Технические требования

- Сервер: WebSocket-сигналинг, аутентификация по токену (JWT от Laravel), проверка прав через API Laravel, TURN/STUN (coturn).
- Клиент: SPA, WSS + WebRTC, русский UI, оформление по стилям и логотипу НЕКСУС.
- Laravel: выдача токена (`/api/nmess/token`), страница ЛК `/lk/messenger`, API прав, раздел в админке.
- HTTPS/WSS, учёт 152-ФЗ при хранении данных.

## 6. Результаты

- Рабочий сервер и клиент в `Nmess/`, интеграция с Laravel, раздел в админке, README с запуском и деплоем.
