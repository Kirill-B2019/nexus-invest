Справочник для layout guest, страниц welcome, ganimed, compliance и др.

1. Шрифт Uicons Regular Rounded (классы fi-rr-*)

Подключение: public/assets/css/style.css → uicons-regular-rounded.css
Шрифт: public/assets/fonts/uicons/uicons-regular-rounded.woff2

Вставка в разметку:

<i class="fi-rr-ИМЯ_ИКОНКИ" aria-hidden="true"></i>

Например: <i class="fi-rr-user"></i>, <i class="fi-rr-quote-right"></i>

Полный список: вид иконки + код для вставки (498 иконок). Клик по коду — копирование в буфер.
