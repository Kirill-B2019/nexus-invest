# UI ЛК: чеклист приемки и smoke-сценарии

## A. Чеклист приемки (по ролям)

### Общий

- [ ] Навигация sidebar/topbar без конфликтов терминов.
- [ ] На всех ключевых экранах корректно работает breadcrumbs.
- [ ] Системные сообщения единообразны (success/error/warning/info).
- [ ] На mobile нет горизонтального скролла на основных страницах.

### Investor

- [ ] Переход к `Мой портфель` из дашборда за 1 клик.
- [ ] Переход к `Все проекты` из дашборда за 1 клик.
- [ ] Уведомления доступны из topbar и sidebar.

### Initiator

- [ ] `Новый проект` доступен из дашборда за 1 клик.
- [ ] `Мои проекты` показывает корректные действия (`Редактировать`/`Просмотр`).
- [ ] Форма проекта: шаги, сохранение черновика, возврат и продолжение.

### Expert

- [ ] Переход на экспертный дашборд доступен из дашборда ЛК.
- [ ] Блок коммуникаций (уведомления/мессенджер) доступен при правах.

### Admin/Moderator

- [ ] `Настройки` и модерация доступны из навигации.
- [ ] На списке модерации действия очевидны на desktop и mobile.
- [ ] На карточке модерации решение (approve/reject) доступно и понятно.

## B. Smoke-сценарии

### Smoke 1: вход и базовая навигация

1. Войти под тестовым пользователем.
2. Открыть `/lk`.
3. Проверить быстрые действия дашборда.
4. Перейти в уведомления и профиль.

### Smoke 2: инициаторский поток

1. Открыть `Мои проекты`.
2. Создать проект, заполнить обязательный минимум.
3. Сохранить черновик.
4. Вернуться к списку и открыть проект повторно.
5. Отправить на модерацию.

### Smoke 3: модераторский поток

1. Открыть список модерации.
2. Перейти в карточку проекта.
3. Выполнить approve/reject и проверить обратную связь.
4. Проверить, что проект исчез/сменил статус в списке.

### Smoke 4: mobile-потоки

1. Открыть ключевые таблицы (`projects/my`, `moderation/index`, `notifications`).
2. Проверить доступность действий через mobile action-control.
3. Убедиться в читаемости и отсутствии перекрытий.

## C. A11y минимальный чеклист

- [ ] Все action-кнопки имеют читаемый label/aria-label.
- [ ] Таблица действий достижима клавиатурой.
- [ ] Видимый focus присутствует на интерактивах.
- [ ] Иконки-действия не являются единственным носителем смысла.
